# TechMind AI Bot 🤖

Your AI-powered tech companion for Telegram.

## Features
- 📰 Latest tech & AI news
- 💻 Programming help & tips
- 🛠️ AI tools & resources
- 📊 Tech trends & insights
- 🔒 Privacy-focused (no data storage)

## Commands
- `/start` - Welcome message
- `/help` - Help and commands
- `/news` - Tech news updates
- `/code` - Programming tips
- `/tools` - AI tools list
- `/trends` - Current trends
- `/feedback` - Send feedback
- `/about` - About the bot

## Deployment

### Local Development
1. Clone repository
2. Install dependencies: `pip install -r requirements.txt`
3. Create `.env` with your bot token
4. Run: `python bot.py`

### Railway Deployment
1. Fork this repository
2. Create a Railway account
3. Connect GitHub repository
4. Add environment variable `TELEGRAM_BOT_TOKEN`
5. Deploy!

## Compliance

- No data collection or storage
